# Changelog

## [0.2.0] - 2026-09-20

### Added

- Added a dockable UI for local LM Studio chat completions.
- Added model discovery through the LM Studio `/v1/models` endpoint.
- Added asynchronous requests using the OpenAI-compatible `/v1/chat/completions` endpoint.
- Added textured 2.5D relief mesh generation from PNG, JPEG, and WebP images.
